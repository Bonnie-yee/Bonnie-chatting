# Bunny Chatting：GPT 项目导入

当前用户明确要求 GPT 保持原状。本包仅作离线维护与恢复资料，不自动上传，不覆盖当前项目指令或 Sources；工作预览源码与提示词不包含在本包中。以下导入步骤仅供将来用户明确授权恢复时参考。

1. 打开项目的指令设置，把「00_项目指令.txt」全文粘贴为项目指令。
2. 向项目 Sources / 添加文件上传 01、02、03、04、06；05 是完整维护代码，可一并上传，日常接话不需要读取它。06 为最新校正，应优先遵守。
3. 在已有项目里为不同男生分别开聊天，直接发截图或最近几句，顺带说阶段和要求，如「第二阶段，含蓄地暗示约饭」。之后同一个人的情况在对应聊天里继续。
4. 模型明确选择 GPT-6.1 Sol，工作模式，极高（xhigh）；不使用自动模型选择，也不为速度降低强度；不要求模型每次重读所有大文件或讲长解释。10秒是目标，不是外部服务的硬保证。

项目能共享上传文件和指令；上传代码是提供维护资料，不等于把本机服务装在项目里执行。HTML 界面和本机程序继续在浏览器与 Mac 上运行。
