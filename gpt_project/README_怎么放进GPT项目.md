# 邦尼🐰的🐶军师：GPT 项目导入

使用自己的 ChatGPT 账号，创建一个新的私有项目，名字可用「邦尼🐰的🐶军师」。

1. 打开项目的指令设置，把「00_项目指令.txt」全文粘贴为项目指令。
2. 向项目 Sources / 添加文件上传 01、02、03、04；05 是完整维护代码，可一并上传，日常接话不需要读取它。
3. 在这个项目里为不同男生分别开聊天，直接发截图或最近几句，顺带说阶段和要求，如「第二阶段，含蓄地暗示约饭」。之后同一个人的情况在对应聊天里继续。
4. 想要快答时选择账号可用的即时模式；不要求模型每次重读所有大文件或讲长解释。10秒是目标，不是外部服务的硬保证。

项目能共享上传文件和指令；上传代码是提供维护资料，不等于把本机服务装在项目里执行。HTML 界面和本机程序继续在浏览器与 Mac 上运行。

本人正向文字 1068 条，分 459 组；逐场景分析 61 组；已认可生成示例 4 组；参考全文 1291 段。ta 的发言不作为风格样本。

资料依据：[OpenAI 官方 Projects 说明](https://learn.chatgpt.com/docs/projects)。后续有新的校正时，更新项目指令或重新上传对应资料。不要把资料放进其他人的账号，也不要共享这个私有项目。
